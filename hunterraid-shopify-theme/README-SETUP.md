# HunterRaid Shopify theme – setup

1. Shopify admin → Online Store → Themes → Add theme → Upload zip → choose HunterRaid-shopify-theme.zip.
2. Products → add "HunterRaid Projector Hunting Game" with your price and compare-at price (e.g. 109.99 / 150).
   Product images are optional; without them the theme shows the built-in HunterRaid photos.
3. Install the Kaching Bundles app and set up your bundles and upsells there.
4. Online Store → Themes → Customize → open the product page → in the "HunterRaid product page" section click
   "Add block" → add the Kaching Bundles app block. It appears just above Add to Cart. Save, then Publish.
   (The home page uses the same section: pick the product in the section settings, or it uses your first product.)
5. Settings → Policies: fill in Refund, Privacy and Shipping policies (the footer links to them).
