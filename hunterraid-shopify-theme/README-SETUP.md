# HunterRaid Shopify theme – setup (built-in bundles, no app needed)

1. Shopify admin → Online Store → Themes → Add theme → Upload zip → choose HunterRaid-shopify-theme.zip.
2. Products → add "HunterRaid Projector Hunting Game" with ONE option (e.g. "Bundle") and 3 variants, in this order:
   - 1 Set — Starter Pack: price 109.99, compare-at 150
   - 2 Sets — Family Pack: price 202.99, compare-at 310
   - 3 Sets — Ultimate Pack: price 294.99, compare-at 470
   The variant names are shown as the bundle names. Product images are optional (built-in photos are used otherwise).
3. Add two more products, untick "This is a physical product" on both:
   - Shipping Protection – 7.99
   - 1-Year Warranty – 7.99
4. Online Store → Themes → Customize → click the "HunterRaid product page" section:
   pick the main product, the Shipping Protection product and the 1-Year Warranty product. Save, then Publish.
5. Turn off / remove the Kaching Bundles block if you added it.
6. Settings → Policies: fill in Refund, Privacy and Shipping policies (the footer links to them).
